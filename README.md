## Boundaries

This is an independent proposal, not the official Total Reformation website. The existing `Falk3n/tr-preview` project and the real business systems are not changed.

The companion uses fictional client Alex. It stores sample choices in the local browser only. No real accounts, bookings, payments, client records or cross-device backend exist. No analytics scripts are included. Normal requests still reach GitHub's hosting infrastructure. Never enter private or health information.

The coach workspace, check-ins, plan publication and cross-tab updates are local simulations. Exercise videos are brief excerpts from TR's public tutorials, not an approved personal programme. Business/service wording requires owner review. No invented testimonials or clinical outcomes are used.

## Run

No build step, dependencies or keys are needed to serve the site. Use any static HTTP server from this directory. All fonts and media used by the pages are local.

## Content provenance

Business photography and video excerpts are from Total Reformation's existing public site/tutorials and remain the property of their owners. This preview republishes selected already-public assets for the authorised pitch. The layouts, visual identities and demo code are original. Reference-brand assets and code are not reused.

Font licences are in `assets/fonts/*-OFL.txt`. Reference sites and the future product boundary are described on the collection page.

Public GitHub Pages preview. `noindex` and `robots.txt` request no indexing; they are not access control. The owner should approve any continued public use after the pitch.
